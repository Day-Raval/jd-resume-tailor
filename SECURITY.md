# Security policy

## Reporting a vulnerability

Email **dayesh.raval@gmail.com** with the subject `jd-resume-tailor security`, or open a private security advisory at https://github.com/Day-Raval/jd-resume-tailor/security/advisories/new.

Please include what you found, how to reproduce it, and which agent you used. You will get a reply within 7 days, and confirmed issues are fixed in a new release listed in CHANGELOG.md.

## Scope

The plugin contains only markdown instructions and a local install script. It makes no network calls, has no MCP servers, and reads or writes only the user's own portfolio bank file.
